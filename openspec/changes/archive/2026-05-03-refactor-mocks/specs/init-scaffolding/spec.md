## ADDED Requirements

### Requirement: Init scaffolding content is source-only, no external asset files
The `dotagents init` scaffold content (example command, skill, instructions, MCP config, env, gitignore, Handlebars provider templates) SHALL be defined entirely within Rust source files. No `include_str!` references to files under `src/mocks/` SHALL exist. The content written to disk during init SHALL be identical to what was written before this refactor.

#### Scenario: Init produces the same files as before
- **WHEN** `dotagents init` is run after the refactor
- **THEN** the set of files written to `.dotagents/` and their contents are identical to pre-refactor output (for the same feature and template selection)

### Requirement: Config content is generated from a builder function
The content written to `config.toml` and `local.config.toml` during init SHALL be generated by `mocks::default_config(features, targets)`. The output SHALL be valid TOML containing a `features` array, a `targets` array, a `schema` key, and a `variables` key.

#### Scenario: default_config produces valid TOML
- **WHEN** `default_config(&["commands", "mcp"], &["claude"])` is called
- **THEN** the returned string parses as valid TOML with `features = ["commands", "mcp"]` and `targets = ["claude"]`

#### Scenario: default_config with empty slices
- **WHEN** `default_config(&[], &[])` is called
- **THEN** the returned string parses as valid TOML with `features = []` and `targets = []`

### Requirement: Each feature type exposes its mock content via mock()
`CommandFeature`, `SkillFeature`, `McpFeature`, and `InstructionFeature` SHALL each expose a `pub(crate) fn mock() -> &'static str` returning their respective example file content used during `dotagents init`.

#### Scenario: CommandFeature::mock() returns non-empty markdown with frontmatter
- **WHEN** `CommandFeature::mock()` is called
- **THEN** the returned string is non-empty and contains YAML frontmatter with a `name` field

#### Scenario: SkillFeature::mock() returns non-empty markdown with frontmatter
- **WHEN** `SkillFeature::mock()` is called
- **THEN** the returned string is non-empty and contains YAML frontmatter with a `name` field
